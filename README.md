# Invitación de XV años

Landing page responsive para celebrar los quince años de Lourdes, creada con
React y Vite.

La celebración está programada para el 17 de octubre de 2026 en el domicilio de
la quinceañera. La hora de recepción indicada es a las 6:00 p. m.

## Iniciar el proyecto

```sh
npm install
npm run dev
```

Para generar la versión de producción:

```sh
npm run build
npm run preview
```

## Personalizar la invitación

- Cambia la fecha de `eventDate` en `src/App.jsx`. La fecha visible y la cuenta
  regresiva se actualizan desde ese valor.
- Edita el lugar, el horario, el itinerario y el código de vestimenta en
  `src/App.jsx`.
- Actualiza las fotografías en `src/styles.css`.

Las fotografías y las tipografías se cargan desde servicios externos y requieren
conexión a internet.
